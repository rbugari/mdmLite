# Docs

## Contenido
- `specs/` especificaciones base y documentos funcionales.
- `planning/` plan principal y decisiones de arranque.
- `product/` backlog y alcance MVP.
- `architecture/` arquitectura tecnica.
- `decisions/` matriz de decisiones abiertas o cerradas.
- `analysis/` analisis de datasets de entrada y notas de discovery.

## Archivo de entrada recomendado
Comenzar por `planning/plan-mdmLite.prompt.md` y luego continuar con `architecture/arquitectura-mvp-mdmLite.md`.

## Documento de cierre v0.1
Para el alcance del release actual, revisar `product/release-v0.1-mdmLite.md`.

## Documento ejecutivo del release
Para presentacion o resumen corto, revisar `product/release-notes-v0.1-mdmLite.md`.

## FAQ ejecutiva del producto
Para explicar rapido que es MDM Lite, con quien compite y por que complementa al catalogo y gobierno, revisar `product/faq-ejecutiva-mdmLite.md`.

## Posicionamiento e integracion en plataformas
Para el encaje con Purview, Unity Catalog, Databricks, Fabric, Snowflake, ELT y medallion, revisar `architecture/integracion-plataformas-y-posicionamiento-mdmLite.md`.

## Continuidad posterior al release
Para mejoras post v0.1, revisar `product/post-v0.1-candidates-mdmLite.md`.
