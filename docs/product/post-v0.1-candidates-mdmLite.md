# Post v0.1 - Candidatos para v0.2

## Objetivo
Registrar las mejoras naturales posteriores al release v0.1 sin mezclarlas con el alcance ya cerrado.

## Prioridad alta
1. Baja logica simple de registros activos.
2. Auditoria visible por fila o por entidad.
3. Login real de administrador.
4. Preview de importacion antes de confirmar.

## Prioridad media
1. Workflow simple de aprobacion visible en UI.
2. Historial de cambios por registro.
3. Filtros mas ricos y paginacion.
4. Validaciones funcionales mas fuertes sobre archivos de importacion.

## Prioridad baja
1. Roles adicionales.
2. Multiempresa.
3. API externa formal.
4. Exposicion por MCP.
5. Asistentes o acciones apoyadas por LLM.

## Criterio para abrir v0.2
Solo deberia abrirse cuando la v0.1 ya este demostrada, documentada y aceptada como base funcional y tecnica.
