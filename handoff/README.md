# Trial Handoff

This folder contains the minimum handoff artifacts for the first controlled MDM Lite trial.

## Contents

1. `package-contents.md` - what to send and what not to send
2. `tester-message.md` - short operator-facing message to send with the package
3. `trial-acceptance-checklist.md` - 10-minute install and acceptance checklist
4. `executive-brief.md` - one-page summary for mail, chat, or sponsor handoff
